## 핵심 메시지 요약

- **평가 측면**: 6개 문제 모두 BM·독립변수·고정변수 정의 완료. 단, #6은 별도 run 없이 #4 결과 재분석, #12는 #4와 동일 run을 공유.
- **코드 측면 (v0.2 시점)**: 
  - **#4/#12, #3 의 평가 토글(chunk YAML, user_q prefix, k sweep, 모드 sweep)은 모두 구현 완료**.
  - **#5 cat5 필터 포팅** 도 완료.
  - 그러나 **Edwin prompt 주입 경로 미구현 → C12 (논문 baseline 0.922) 직접 비교 불가** 상태가 최우선 블로커.
- **공통 인프라 5개 (snapshot / 파일럿 wrapper / 자동 판정 / MS 집계 / Edwin 주입)** 모두 v0.2 시점 미구현 → 본 실험 진입 전 마무리 필요.

> ⚠️ 본 정리는 `20260425_modified_list_v0_2.md` (v0.2) 기준이며, 그 이후 추가 구현이 진행됐다면 차이 있을 수 있음. 최신 상태는 코드 점검으로 재확인 권장.
